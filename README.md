# OSTRO Reels — Blender pipeline

Конвейер вертикальных видео: манифест → аудио и таймлайн → редактируемая
Blender-сцена → покадровый рендер → H.264/AAC MP4. Смена сцен привязана
к репликам, а анимация вычисляется из времени и допускает перемотку назад.

В публичном примере используется процедурный робот. Он не основан на внешности
человека. В репозитории нет моделей коллег, их имён, голосовых клонов, частных
сценариев, записей или готовых сцен с локальными путями.

## Локальный пример без API

Нужны Python 3.10+, Blender 4.5 и FFmpeg. Установите Blender и FFmpeg в PATH
либо задайте `BLENDER_EXE` и `FFMPEG_EXE` в терминале.

```sh
python -m venv .venv
# Активируйте окружение стандартным способом для своей ОС.
python -m pip install -r requirements.txt
python ostro.py doctor
python tools/setup_demo.py
python ostro.py episode plan demo
python ostro.py episode run demo --smoke
```

Результат: `build/demo/demo.mp4`; сцена: `build/demo/scene.blend`.
Smoke-пример — 1,2 секунды в 216×384 / 10 fps. В нём намеренно нет речи:
подпись сопровождается локально созданной тишиной. Платные сервисы,
аккаунты и API-ключи для него не нужны.

Без `--smoke` применяются разрешение и FPS из манифеста.
Все результаты, аудиокеши и машинные настройки исключены из Git.

## Этапы

`python ostro.py episode <stage> demo`, где stage:

- `plan` — проверка манифеста и перечень операций;
- `audio` — аудиокеш, сведение, словные тайминги и амплитуда рта;
- `scene` — сцена Blender из шаблона studio, conference или arena;
- `preview` — первый, средний и последний кадр;
- `render` — последовательность PNG;
- `mux` — MP4;
- `run` — все этапы по порядку.

Для настоящей речи настройте собственный разрешённый голос в
`.local/voices.json`, задайте `ELEVENLABS_API_KEY` в окружении и уберите
`cached_audio` у соответствующей реплики. Точная структура и правила —
в `docs/PIPELINE.md`. Незаданный голос останавливает генерацию; чужая
запись не подставляется автоматически.

Внешний TTS вызывает платный API только по явной команде audio/run для реплик
без cached_audio. Сборка и рендер не публикуют видео в социальные сети.

Публичная версия сохраняет общий конвейер. Персональные производственные
эпизоды и генераторы моделей реальных людей в неё не включены.
